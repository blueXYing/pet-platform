## 已确认（逐项）

1. **STR-D1**：三条件合取可见性（merchantEnabled∧storeEnabled∧acceptsNewOrders）、同事务判定、失败关闭；错误两分（确认不存在/无资格→隐藏或 404；故障/未知→503）不得混同。
2. **STR-D2**：九字段投影；评分/月售/距离/收藏/评价/相册/促销/人员/简介/营业时间等延后（无事实源或 §28 取消）；**延后仅界定本切片范围，不代表完整门店页面验收完成**。
3. **STR-D3**：城市目录（服务端控制、省略=全部开放城市集合、未知城市 400）；compat 缺行/城市码损坏=完整性反例整页 503；**v0.2 增补完整性程序**（SQL 巡检+回归反例+告警与修复 runbook），检查范围=通过资格合取但缺 compat 行（或 city_code 词法损坏）的商家。
4. **STR-D4**：`merchantId,storeId` 数值升序；page 1..10000/pageSize 1..50 默认 20；信封 items/page/pageSize/total；无 sort 参数。
5. **STR-D5**：详情 404 `STORE_NOT_FOUND` 不区分原因（防探测）；与店内服务列表 200 空页语义并存不矛盾；404 语义沿用角色F 修复后的结果（合并顺序：F 先并→本切片 rebase）。
6. **STR-D6**：pet-merchant-api 第五查询 `MerchantStoreDisplayApi`（pageDisplayStores/getDisplayStore；cityCodes 集合入参、整页一次资格判定、repeatable-read 快照、错误两分）；唯一 Writer 规则独立 commit 披露。
7. **STR-D7**：分类筛选与关键词搜索延后（categoryId/keyword 不接受，未知参数 400），登记承接；备选方案留档未启用。
8. **STR-D8**：**核对结论=无冲突批准，按 PRD 匿名浏览执行**，四条浏览路由统一匿名 GET（可选 Bearer：无 token 匿名放行、无效/过期 token 仍 401、有效 token 正常；可见性与登录无关；写操作与其他 C 端路由行为不变；改动收敛在路径清单机制），契约与访问控制同步补齐。
9. **电话**：本轮 phoneMasked，不宣称拨号功能；边界问题单列剩余待裁决。
