# 宠物档案页实现基线（本阶段三页）

适用范围：Figma `78:2817`(模块区)、`78:3076`、`95:1481`、`95:1844`，版本 `2397539525915641008`。数值以各页 spec.json 精确值为准，本文为速查；不能将本基线外推到其他页面。

## 原稿单位与结构

- 设计画布宽 402；实现为同一组件按 `windowWidth / 402` 缩放（CSS 变量 `--pet-unit`），规避 rpx 取整与 calc 小数截断。
- 测试画布（`referenceCanvas=1`）：unit=1 的 402 组件画布，置于实际模拟器内。**必须在 414 窗口采集**（402 ≤ 视口宽）；390 窗口会裁掉画布末 12 列。
- 列表页只实现 78:2817 的宠物档案模块区（画布 402×312，设计 y282..594 平移）；首页其余模块不在本阶段。
- 页面源码路径：`consumer/pages/pet-archive/{index,detail,form}`（已注册为普通分包 `consumer/pages/pet-archive`，路由不变；主包 710KB / 分包 1.74MB，均低于 2MB 平台上限）。

## 状态与交互（预览通道）

- 预览路由：`?preview=1`；画布模式追加 `&referenceCanvas=1`；场景：`scenario=list-empty|load-error|save-error|form-brother|form-sister|expired`；`petId` 进入编辑。
- 覆盖状态：加载/空列表/加载失败重试/有数据/表单校验错误/保存中/保存成功/保存失败重试/会话失效/未接入口提示。
- 删除确认：原稿未绘制删除入口；采用长按列表卡 + 原生 `Taro.showModal`，零新增视觉样式（已登记）。
- 预览保存只更新内存并提示"预览数据已更新"；无 `preview` 参数的入口不显示 fixture。
