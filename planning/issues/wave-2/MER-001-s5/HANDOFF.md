# MER-001 S5 申请审核领域运行切片

基线PR53 `9d6b828`，用户明确“那么请你实施”后启动。PR52已合入develop；本轮在独立实施分支推进，不自动合并PR53或本轮PR，不部署生产。

## 已实现范围

- merchant-api / merchant-biz：申请创建、不可变草稿版本、提交、领取/释放、人工核验、通过/拒绝/补正与权威读取；MyBatis XML访问本域表，requestId持久化绑定。APPROVE同事务写商家/门店ACTIVE、profile、decision、audit和事务Outbox，签约保持独立。
- admin-api / admin-biz：执行前与回执重放的当前会话/动作/scope复核；MySQL锁读避免外层RR旧快照隐去撤权；列表另有真实集合入口检查，空结果不跳过鉴权。详见[AUTH](AUTH.md)。
- notification-biz：严格审核事件消费、消费去重与强制站内消息原子写入、UTC时间存储；失败回滚并交由既有Outbox重试。三类决定均采用申请人可见意见，不透传内部字段。
- boot：跨域授权适配与内部领域装配，真实审核事实加入协议与新单资格读取快照。`pet.merchant.application.enabled`默认未设置；缺少真实Provider不能成功装配。通知另需Outbox及notifications-enabled同时开启。
- 小程序：按用户要求由GPT-6 Astra medium实现申请/协议客户端、严格wire解码、会话/工作区绑定、稳定requestId及未知结果保留。77项测试、类型检查、微信构建及包体检查通过，详见[FRONTEND](FRONTEND.md)。新仓储尚未注册页面。
