# Open Decisions

以下来自最终 SSOT 的非核心边缘未决项，不阻塞核心工程启动：

1. 分钟级排期是否提供快速生成工具；
2. 商家拒绝退款原因分类字典；
3. 微信公众号 / 订阅消息具体接入方式；
4. 人工客服具体承载方式；
5. 黑名单未来影响哪些社区行为。

另外，“成为服务者”类灵活服务者能力不作为当前已封板 V1.0 核心范围实现，除非后续产品裁决明确加入。
