# Preliminary Audit Findings

这些不是新的产品裁决，而是 Work 第一次进入项目时必须核验的风险。

## A-001 运营 PRD 的“7天资金监管冻结期”
运营 PRD 的交易履约描述中出现“核销后资金进入 7 天售后监管冻结期”。
最新 SSOT/当前技术基线主要明确售后 7 天窗口，但现有核心技术基线没有完整冻结/结算状态机。

处理：
- 不允许 Worker 自行实现结算冻结规则；
- Work 在 Bootstrap Validation 中核对其是否属于仍有效 V1 产品规则、旧文案残留或后续结算需求；
- 若需要产品确认，登记待产品裁决；
- 该项不阻塞用户/服务/排期/订单基础工程启动，但可能阻塞最终结算模块。

## A-002 运营 PRD 商家签约/服务商签约细节
运营 PRD 包含商家审核后“待签约/服务商签约”的流程描述。
需要 Work 对照最终 SSOT 与技术基线确认具体签约 Provider/状态是否已进入 V1 技术范围。
在未核验前，不允许 AI 自行选择第三方签约实现。

## A-003 人工客服承载方式
SSOT 明确“人工客服做”，但具体承载方式未封板。
Customer Service 只建立模块边界，不提前实现具体第三方承载。
