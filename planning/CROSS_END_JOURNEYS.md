# Cross-End Journeys

## J1 正常预约履约主链路
商家/门店有效 → 服务上架 → 员工/排期可用 → C端浏览 → 选择宠物/时间 → 订单待支付 → 支付成功 → 商家30分钟确认/自动接单 → 待服务 → 核销 → 已完成 → 评价/售后窗口。

## J2 服务开始前退款
已支付预约 → 开始前用户退款 → 自动创建全额退款 → refund_order 创建后禁止核销 → 渠道成功 → 已退款 → 预约释放 → 普通全额退款权益恢复。

## J3 服务开始后退款/售后
预约已开始 → 用户退款 → 商家24小时处理 → 同意则全额退款；拒绝则展示原因并允许售后 → 运营终局裁决。

## J4 售后 × 核销竞态
未核销售后处理中且未创建 refund_order → 商家仍可核销；若核销先成功，当前未履约售后失效；若 refund_order 先创建，后续核销禁止。

## J5 支付超时/迟到支付
支付超时且渠道确认未支付 → 订单关闭、资源/冻结券释放；之后若渠道真实确认支付成功 → 不恢复订单/预约/优惠券 → 按渠道真实支付金额自动全额原路退款。

## J6 商家下线
运营立即下线 → 停止新订单 → 已成立存量订单、退款、售后继续处理。

## J7 第三方团购
商家核销美团/点评券 → 独立第三方核销记录 → 不创建平台订单/支付/退款/GMV。
