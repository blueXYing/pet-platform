# 部署开关与五层配置清单 v2.0

状态：已批准执行（2026-11-24 方案 B 配置收口与历史场景开关彻底瘦身）。本文档是 `pet-boot` 运行时配置分层与剩余边界开关的**单点权威清单**。

---

## 1. 五层配置架构（Single Source of Truth）

同一配置值只在唯一位置定义，消除 `application.yml` / `application-local.yml` / `ops/*.env.example` / 启动命令多副本漂移：

| 层级 | 文件 / 来源 | 职责 |
|---|---|---|
| 1. 公共默认值与敏感项绑定 | `backend/pet-boot/src/main/resources/application.yml` | 跨环境一致的公共默认值；所有敏感项与机器路径的 `${ENV:}` 唯一绑定入口（无明文默认值）；不设默认 `spring.profiles.active`（避免单测或漏传 profile 的生产实例误入 `dev`）。 |
| 2. 开发环境非敏感配置 | `backend/pet-boot/src/main/resources/application-dev.yml` | `SPRING_PROFILES_ACTIVE=dev`；开启全量四底座、拉卡拉 `SIT`、允许本地 HTTP 素材与 DEMO 支付。 |
| 3. 测试 / SIT 非敏感配置 | `backend/pet-boot/src/main/resources/application-test.yml` | `SPRING_PROFILES_ACTIVE=test`；开启全量四底座、拉卡拉 `SIT`、`settle-type=1`、开启 DEMO 支付；禁止 HTTP 素材。 |
| 4. 生产环境非敏感配置 | `backend/pet-boot/src/main/resources/application-prod.yml` | `SPRING_PROFILES_ACTIVE=prod`；开启全量四底座、拉卡拉 `PRODUCTION`、`settle-type=0`、强制关闭 DEMO 与 `maintenance`。 |
| 5. 密钥、密码与机器路径 | 进程环境变量（本地开发可选仓库根目录 `.env.local`） | 唯一模板见 `ops/backend-secrets.env.example`；本地通过 `spring.config.import: optional:file:./.env.local[.properties]` 自动加载，严禁入库。 |

> **统一环境变量口径**：
> - Redis 全模块共用 `REDIS_HOST` / `REDIS_PORT` / `REDIS_PASSWORD`；
> - 微信小程序 AppID/Secret 全模块共用 `WECHAT_MINI_APP_ID` / `WECHAT_MINI_APP_SECRET`（兼容旧名 `AUTH_WECHAT_APP_ID/SECRET`）；
> - OSS 统一走 Spring 属性 `pet.oss.*`（由 `OSS_ENDPOINT`/`OSS_REGION`/`OSS_BUCKET`/`OSS_ACCESS_KEY_ID`/`OSS_SECRET_ACCESS_KEY`/`OSS_PUBLIC_BASE_URL` 注入），私有素材、社区媒体、营销素材不再直接调用 `System.getenv(...)` 绕过 Spring 配置。

---

## 2. 精简后的开关总表

原并行开发阶段遗留的 ~85 个业务子切片/HTTP/Worker 场景开关已全部拆除。`dev / test / prod` 三套环境装配**完全一致的完整业务能力**，不再需要人工拼装开关组合。

### 2.1 四大基础设施底座开关（`dev / test / prod` 统一 `true`，裸 `application.yml` 默认 `false` 供隔离单测使用）

| 开关 | 自动装配范围 | 依赖的外部凭据 / 基座 |
|---|---|---|
| `pet.auth.admin.enabled` | 管理端会话/RBAC/审计、Snowflake、全部 `/api/v1/admin/**` 安全链、运营治理面（64/65/券发放与作废/积分配置/反馈处理/社区审核/营销与活动管理） | Redis、`ADMIN_AUTH_KEY_ID` / `MAC` / `ENCRYPTION`、`ADMIN_AUTH_ORIGIN`、`ADMIN_AUTH_AUDIT_PATH` |
| `pet.auth.c.enabled` | C 端微信会话、全部 `/api/v1/c/**` & `/api/v1/merchant/**` 安全链、宠物/地址/通知/订单读与创建/评价与申诉/积分/反馈/社区/营销 | Redis、`WECHAT_MINI_APP_ID` / `WECHAT_MINI_APP_SECRET`、Snowflake |
| `pet.private-assets.enabled` | 私有素材 OSS/ClamAV、封面直传签名、商家入驻/协议/城市/店铺资料、服务目录读写、门店读、排期读写、收藏足迹、账号注销与到期 Worker | `OSS_*` 五元组、`PRIVATE_ASSET_*`、`MERCHANT_SUBJECT_*`、`MERCHANT_PROTECTED_*` |
| `pet.payment.enabled` | 支付地基/拉卡拉发起/支付中心与查单 Worker、迟到退款与 Worker、自动确认与修复 Worker、商家接单/拒单/客户/经营统计、改期、核销凭据与完成（含员工核销）、C/M 退款申请与 Worker（服务前自动全额退款常开）、售后工作流与原路退款、运营交易读与处置 Worker | 拉卡拉证书/私钥/参数 AES 密钥、`ORDER_MERCHANT_PROTECTION_KEY`、`REFUND_APPLICATION_PROTECTION_KEY`、`VERIFICATION_CREDENTIAL_*`、`AFTERSALE_PROTECTION_KEY`、`pet.refund.application.reason-codes`、`aftersale-catalog.yml` |

> **常开核心能力（无任何开关）**：Transactional Outbox 与全部站内通知消费者、员工档案与身份读、排期保护底座、原子下单与 10 分钟占位过期 Worker、券生命周期、积分任务与退款扣回、百科公开读。

### 2.2 运维与安全边界开关（仅保留 4 个）

| 开关 | 默认值 | `dev` | `test` | `prod` | 用途 |
|---|---|---|---|---|---|
| `pet.auth.admin.maintenance` | `false` | `false` | `false` | `false` | 宿主机交互式初始化首个超管账号 runner（非 Web 入口） |
| `pet.payment.center.demo.enabled` | `false` | `true` | `true` | `false` | 测试专用 DEMO 支付业务方；`PRODUCTION` 环境下 guard 强制拒绝启动 |
| `pet.notification.delivery.enabled` | `false` | `false` | `false` | `false` | 外部微信订阅消息投递（待接入真实微信适配器后按需开启；站内通知常开） |
| `pet.marketing.campaign.category-validation.enabled` | `false` | `false` | `false` | `false` | 营销活动分类码强校验（存量历史数据清理完成后开启） |
| `pet.payment.settlement.enabled` | `false` | `false` | `false` | `false` | 支付中心阶段 2 订单分账与结算总开关（78 号契约；开启强依赖 `pet.payment.enabled=true` 与平台商户配置，默认关闭） |

> 另：`pet.merchant.staff-member.enabled` 因主装配树尚未接入 `UserPhoneVerificationApi` 暂保持 `false`；各隔离测试库专用 `pet.*.migration-enabled` 永不在环境 yml 中开启。
