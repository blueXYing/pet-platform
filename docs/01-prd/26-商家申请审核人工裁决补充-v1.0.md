# 商家申请审核人工裁决补充 v1.0

状态：人工已批准。2026-09-17，用户在解释补正与审核建档含义后明确回复“四项建议确认”。本文件覆盖三端原PRD相应不一致表述，原Word文件保留。

## 已确认四项

1. **门店照片**：提交申请必填1～6张。此处确认数量与必填性，不扩大其它材料要求。
2. **OCR异常与人工核验**：OCR不可用或识别失败时，可以提交到审核中并标记待人工核验；清晰的必需证件原件仍须提供，已知证件过期仍拦截。主体、编号、有效期及去重核验完成前不能审核通过，不以申请人自报信息或OCR失败推断核验成功。
3. **补正与重提**：REQUEST_CORRECTION是审核决定类型，申请状态仍为REJECTED，表示本轮未通过且可修改。对申请人可显示“需补充资料”；修改产生新的材料版本，重新提交进入REVIEWING。原材料、审核意见与决定留痕，不新增第五个公开申请状态，不解释为永久禁止入驻。
4. **审核通过与经营资格**：APPROVE建立正常商家档案，merchant.status写ACTIVE；审核通过与协议同意为独立事实，ACTIVE不代表可以接单。未SIGNED仍不能开展新业务；工作台/新单继续检查审核、签约、商家/门店状态及当前账号权限。

## 保留边界

- 不修改单运营、无内部双人审批、无额外MFA、幂等、后端鉴权、脱敏和审计要求。
- 不强制重签、下线存量履约等已批准规则保持；冻结写动作未决部分不由本次批准自动开放。
- 审核结果强制站内通知仍须交付，查询页面不能替代通知。
- 本回执确认以上四项业务规则，不宣称申请审核、OCR/私有材料、通知或完整MER-001已经实现；具体接口、Schema和事件按CCR同步及对应Owner交接。
- 不将“四项建议确认”解释为PR52合并授权或生产发布授权。
