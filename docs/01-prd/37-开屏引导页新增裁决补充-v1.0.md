# 开屏引导页新增裁决补充 v1.0

- 裁决日期：2026-10-21
- 裁决人：用户（产品负责人）
- 触发场景：V1 验收期（用户从首页开始人工走查）发现 Figma 设计稿存在三屏开屏引导（「登录广告展示界面1/2/3」），而 PRD/SSOT 无此需求条目、工程侧此前按「启动页=首页（pages[0]）」口径未实现；用户裁决补做。
- 状态：已实现（frontend-miniapp `consumer/pages/onboarding`，普通分包）。

## 一、裁决内容

1. **新增能力**：C 端开屏引导页，三屏静态滑动（Figma 用户端 10:108 / 33:40 / 33:58，402x874）。PRD 此前无此条目，本裁决即授权依据；不涉及任何后端契约/Schema/Event 变化（纯前端、零接口）。
2. **显示时机**：仅首次打开显示。完成（「开始体验」）或跳过均写本地标记 `consumer:onboarding-done`，之后直达首页；清缓存/重装会再次显示。
3. **第三屏文案保留原稿**「发动态、晒萌宠 找同城伙伴」——该表述宣传社区能力，而社区（COM-001）经 2026-10-14 裁决 V1 不做；用户知情后裁决接受该宣传口径偏差，不改文案、留待 V2 社区启动时消除。
4. 广告位形态（Figma 画板原名「登录广告展示界面」）**不采用**：V1 无运营配置广告能力，按静态写死三屏实现；运营化改造留待后续版本需求。

## 二、实现口径

- 分包与素材：`consumer/pages/onboarding`（普通分包），Figma 原切图 11 张经压缩（背景 JPG q80 / 透明 PNG 256 色）共约 1MB，分包总量 1042KB 合规；主包零增量。
- 视觉：节点绝对坐标 ×(windowWidth/402) 还原；按钮/圆点色值取 Figma fills（平台蓝 #5baae8、圆点高亮 #5baae8/常态 #ebebeb）；英文/中文副题 Figma 标 #ffffff 为失效层，按渲染实测 #B09A8A 落地。底部圆点/按钮按设计底部留白锚定屏底，适配长屏。
- 接线：home（启动页）首次 mount 探测标记，未完成则 navigateTo 引导页；引导页 finish 写标记后 navigateBack。静默登录在 app 层进行，不受影响。
- 门禁：typecheck / build:weapp / 前端单测 614 全绿；DevTools 模拟器逐屏截图与原稿对比通过，首启出现→翻页→完成→再次冷启动不再出现的全链路验证通过。
