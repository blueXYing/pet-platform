# 售后退款优惠券返还：SSOT 对齐裁决补充

状态：人工已批准。来源：用户 2026-10-15 针对 PR #168（CPN-001/002 优惠券全链，61 号契约）交付时披露的「PRD 售后存在退款不返券与 SSOT §9.1 冲突」遗留项拍板"按 SSOT 执行"（即售后全额退款同样返券）。本文件只登记该对齐事实与执行口径，不新增用户未批准的产品规则；格式沿 22/24/32/33 号裁决补充先例。

## 冲突条款与对齐结果

- 冲突原文（C 端 PRD §5.1.21「我的优惠券」业务规则·退款返还规则）："订单售后存在退款时，该订单使用的抵扣券不返还（已核销不退）。"
- 权威口径（SSOT §9.1/§9.2，资料优先级最高）：全额退款成功且原优惠券仍处有效期 → 恢复可用（剩余有效期不足 24 小时的延长至退款成功后 24 小时）；部分退款 → 不返优惠券。
- 对齐执行：C 端 PRD §5.1.21 该条款已修订为"订单售后存在退款时，若退款为全额退款且原券仍处有效期，该订单使用的抵扣券恢复可用状态并返还至用户券包（剩余有效期不足24小时的延长至退款成功后24小时）；部分退款不返还"，修订处已插入修订注记 bullet 标注裁决来源与日期（2026-10-15）。其余 PRD 内容零改动。

## 执行口径（与既有实现一致，无代码变化）

- 返券判定只看 refundType：FULL 返券、PARTIAL 不返券；不按退款来源（售后/商家同意/服务前/拒单）区分。
- 迟到支付（LATE_PAYMENT_TIMEOUT）一律 NOOP 不返券（SSOT §二十二，CPN-005）。
- 实现载体：`COUPON_REFUND_RESTORE` 消费者消费 `RefundSucceededEvent.v1`（PR #168 已交付，台账 `CPN:RESTORE:{refundOrderId}` + 状态 CAS 幂等）。
- 运营端 PRD §6.4 券实例状态机（"订单全额退款成功 → 已领取（恢复可用）；售后部分退款不返还平台券"）本已与 SSOT §9.1/§9.2 一致，无需改动。
