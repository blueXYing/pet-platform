# 宠物平台 V1.0 测试发布门禁 v0.1

## 1. V1.0 核心发布 Gate

### Gate A：架构边界

必须全部通过：

```text
biz -> biz 依赖 = 0
跨模块 Repository/Entity 引用 = 0
Controller 直接写其他模块数据 = 0
*-api 中数据库实现注解 = 0
```

### Gate B：交易一致性

必须全部通过：

```text
一单多退款 = 0
一单多成功核销 = 0
一单多评价 = 0
预约超卖 = 0
同一优惠券重复冻结/使用 = 0
重复回调重复扣/退 = 0
```

### Gate C：核心时限

FakeClock / Scheduler测试全部通过：

```text
支付10分钟
预约临时锁10分钟
商家接单30分钟
商家退款处理24小时
核销后售后7天
未核销拒绝退款售后7天
评价30天
```

### Gate D：退款/核销竞态

必须通过：

```text
refund_order 创建先成功 → 后续核销=0
未履约售后中核销先成功 → 旧售后退款成功=0
```

### Gate E：迟到支付

必须通过：

```text
PAYMENT_TIMEOUT关闭后迟到支付
→ 原订单不恢复
→ 不进入PENDING_CONFIRM
→ 不恢复预约
→ 不碰已释放优惠券
→ FULL退款金额=channelPaidAmount
→ 最终REFUNDED
```

### Gate F：退款后置一致性

普通FULL退款：

```text
预约释放
优惠券按规则恢复
订单奖励积分全部扣回
```

PARTIAL：

```text
优惠券不返
奖励积分按比例四舍五入扣回
已核销评价不计分
未核销无评价资格
```

LATE_PAYMENT_TIMEOUT FULL：

```text
预约不恢复/已释放则NOOP
优惠券不二次恢复
正常情况下无订单奖励积分
```

### Gate G：灾难恢复

必须至少模拟：

```text
Scheduler停机
Outbox停机
Consumer失败
支付回调丢失
退款回调丢失
渠道UNKNOWN
Redis不可用
Worker lease超时
```

恢复后核心业务最终一致。

## 4. 第一批跨端 E2E（Web + 微信小程序）

建议只覆盖最高价值闭环：

```text
E2E-01 正常下单→支付→商家接单→核销→评价
E2E-02 支付→30分钟自动接单
E2E-03 服务前退款→退款成功
E2E-04 服务后退款→商家拒绝→售后→运营退款
E2E-05 未履约售后处理中→商家核销→旧售后失效
E2E-06 运营部分退款→评价不计分
E2E-07 支付超时→迟到支付→自动退款
E2E-08 商家下线→新预约禁止→存量订单仍履约
```
